**Tool ID:** `workEmailToLinkedinWaterfall` · **Credits:** 2 per run

Find linkedin profile url for a person/contact using work email.

**Best for:** Finding linkedin profile url from work email.

## Inputs

Send these in `inputs`.

| Name | Required | Description |
| --- | --- | --- |
| `email` | Yes | The person's work email to resolve to a LinkedIn profile. |

## Options

Optional configuration. Send these in `options`.

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `workEmailToLinkedinProviders` | array&lt;string> | No |  | Ordered list of provider tool IDs to try for work-email → LinkedIn resolution. Omit to use Bitscale's tuned default chain. |

## Output

Returns LinkedIn profile URL from a work email address.

`result.data` looks like:

```json
{
  "linkedin_url": "https://www.linkedin.com/in/janedoe",
  "other_info": {},
  "provider": "Findymail"
}
```

## Example

```bash
curl -X POST "https://api.bitscale.ai/api/v1/tools/workEmailToLinkedinWaterfall/run" \
  -H "X-API-KEY: $BITSCALE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"email": "john.doe@acme.com"}}'
```

See [Tools API](/api-reference/tools/overview) for the response format and polling.
