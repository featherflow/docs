**Tool ID:** `linkedinCompany` · **Credits:** 1 per run

Give a company's LinkedIn URL, get details of the company including description, employees, locations, etc.

**Best for:** When you want to get details of a company from LinkedIn.

## Inputs

Send these in `inputs`.

| Name | Required | Description |
| --- | --- | --- |
| `companyLinkedinUrl` | Yes | The company's LinkedIn URL. |

## Output

Flat company fields plus `raw`, the provider's untouched response.

## Example

```bash
curl -X POST "https://api.bitscale.ai/api/v1/tools/linkedinCompany/run" \
  -H "X-API-KEY: $BITSCALE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"companyLinkedinUrl": "https://www.linkedin.com/company/stripe/"}}'
```
