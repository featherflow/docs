**Tool ID:** `linkedinPerson` · **Credits:** 1 per run

Give a person's LinkedIn URL, and get a details of the person including education, experience, skills, etc.

**Best for:** When you want to get person's details from LinkedIn.

## Inputs

Send these in `inputs`.

| Name | Required | Description |
| --- | --- | --- |
| `linkedinUrl` | Yes | The person's LinkedIn profile URL. |

## Options

Optional configuration. Send these in `options`.

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `includeSocialMetrics` | boolean | No | `false` | OPT-IN extra scrape ("Scrape extra details" in the Tweak section). Defaults to false. When true the column makes one additional call per row and also returns followersCount and connectionsCount, which the base profile scrape does not carry. |

## Example

```bash
curl -X POST "https://api.bitscale.ai/api/v1/tools/linkedinPerson/run" \
  -H "X-API-KEY: $BITSCALE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"linkedinUrl": "https://www.linkedin.com/in/john-doe/"}}'
```
