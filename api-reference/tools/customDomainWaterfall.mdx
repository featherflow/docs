**Tool ID:** `customDomainWaterfall` · **Credits:** 1 per run

Enrich company data from a domain by cascading through ~10 company-enrichment providers and returning the first quality hit. Optional company LinkedIn URL boosts coverage.

**Best for:** When you only have a company domain (optionally with LinkedIn URL) and need full company details with maximum coverage.

## Inputs

Send these in `inputs`.

| Name | Required | Description |
| --- | --- | --- |
| `domain` | Yes | The company domain. |
| `linkedinUrl` | No | The company's LinkedIn URL. Optional — boosts coverage. |

## Options

Optional configuration. Send these in `options`.

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `companyDomainEnrichProviders` | array&lt;string> | No |  | Ordered list of provider tool IDs to try (e.g. ["enrichCompanyFromDomain","datagmaCompanyEnrich","leadMagicCompanyEnrich"]). Omit to use Bitscale's tuned default chain. |

## Output

## Example

```bash
curl -X POST "https://api.bitscale.ai/api/v1/tools/customDomainWaterfall/run" \
  -H "X-API-KEY: $BITSCALE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"domain": "acme.com", "linkedinUrl": "https://www.linkedin.com/company/acme/"}}'
```
