## Options

Optional configuration. Send these in `options`.

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `extendedThinking` | boolean | No | `false` | Enable extended/long thinking — the model reasons longer before answering (higher latency/cost). Not every model offers it; check the model's schema. Defaults to false. |
| `webSearch` | boolean | No | `false` | OPT-IN web search. Enabling web search adds latency and cost. |

## Prompt

This tool needs a `prompt`: the full instruction, with the data to work on written into it.

`extendedThinking` is not available on `gpt-4o-mini`, `gpt-5`; sending it returns `400`.

## Output

The answer comes back as text in `result.raw`. Asking for JSON in the prompt still returns a string, often inside a Markdown code fence, so parse it yourself.

```json
{
  "tool_id": "claude-haiku-4-5",
  "credit": 1,
  "raw": "Stripe sells payment APIs and financial infrastructure for internet businesses."
}
```

## Example

```bash
curl -X POST "https://api.bitscale.ai/api/v1/tools/claude-haiku-4-5/run" \
  -H "X-API-KEY: $BITSCALE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "In one sentence, what does stripe.com sell?"}'
```

See [Tools API](/api-reference/tools/overview) for the response format and polling.
