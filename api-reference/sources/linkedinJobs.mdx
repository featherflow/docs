**Source type:** `linkedinJobs`

Search LinkedIn job postings by title / description keyword / location / experience / type / workplace and return each job as a row (title, company, location, description, posted date, URL). Mirrors the 'LinkedIn Job Search' dialog in the Bitscale UI.

<Note>
Up to `limit` (max 100) rows per page. Page with `page` while `has_more` is `true`. Count is not available. 1 credit per row returned.
</Note>

## Filters

Send these in `filters`.

| Name | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `title` | string[] | No |  | Job titles / title keywords to match (OR). Example: ['Sales Engineer', 'Solutions Engineer']. Multi-word entries are ANDed; pass separate entries to OR. |
| `description` | string[] | No |  | Free-text keywords that must appear in the job description (OR). Useful for skill/tool targeting, e.g. ['Salesforce', 'HubSpot']. |
| `searchLocationIds` | string[] | No |  | Location filter. Pass canonical location labels (PDL names) — e.g. ['United States', 'California, United States', 'London, England, United Kingdom']. Not actual IDs despite the field name; the backend wraps each value in quotes and ORs them. |
| `searchLocationName` | string | No |  | Alternative to searchLocationIds for a single location string. Use searchLocationIds when passing multiple locations. |
| `experienceLevel` | string[] | No |  | Seniority filter. Use the exact labels below. One of: `Internship`, `Entry Level`, `Associate`, `Mid-Senior Level`, `Director`, `Executive`. |
| `jobType` | string[] | No |  | Employment type filter. One of: `Full-time`, `Part-time`, `Contract`, `Temporary`, `Volunteer`, `Internship`, `Other`. |
| `workplaceType` | string[] | No |  | Work setting filter. Note: if you pass ONLY 'Remote' the backend restricts to remote-only; if you pass only on-site/hybrid it restricts to non-remote; mixed selections return both. Prefer the `remote` boolean below when you just want 'remote-only yes/no'. One of: `On-site`, `Remote`, `Hybrid`. |
| `remote` | boolean | No |  | Remote-only toggle (matches the 'Remote only' switch in the UI). true = remote jobs only, omit/null = all workplace types. Takes precedence over workplaceType when both are set. |
| `onlyCountries` | boolean | No |  | Location routing mode. true = country-only (matches how the UI's 'Only countries' switch works and enables the RapidAPI fallback path). false = allow granular city/region locations. Defaults to true when omitted; the backend also auto-infers this from the resolved location's feature_name, so only set it explicitly to override that inference. |
| `timePeriod` | string | No |  | Recency window for job posting date. Defaults to 'last_7d'. Use 'last_n_days' together with daysBack (1–180) for a custom window. One of: `last_24h`, `last_7d`, `last_n_days`. |
| `daysBack` | number | No |  | Custom recency window in days, 1–180. Only applies when timePeriod = 'last_n_days'. |
| `sortBy` | string | No |  | Result ordering. 'desc' (date descending, most recent first) is the default. One of: `desc`, `asc`. |

## Example

```bash
curl -X POST "https://api.bitscale.ai/api/v1/sources/linkedinJobs/search" \
  -H "X-API-KEY: $BITSCALE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"filters": {"description": ["Salesforce"], "experienceLevel": ["Mid-Senior Level", "Director"], "jobType": ["Full-time"], "searchLocationIds": ["United States"], "sortBy": "desc", "timePeriod": "last_7d", "title": ["Sales Engineer", "Solutions Engineer"], "workplaceType": ["Remote", "Hybrid"]}, "limit": 25}'
```
